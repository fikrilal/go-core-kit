# ci-cd

One gate decides: `make verify` runs `gokit verify --profile full`. CI runs the
same command, so a green local run and a green pipeline mean the same thing.

## Profiles

- `fast` — knowledge, contract, format, vet, lint, secrets, tests. What you run
  while working.
- `full` — fast plus builds (both lanes), the drift check, the OpenAPI lint, and the
  gate-honesty probes.
- `ci` — what CI runs; currently the full profile.
- `pg` — the Postgres lane: `make verify-pg` builds, vets, lints, and tests with
  `-tags pg`, against a real Postgres service in CI so the lane's guarded tests run
  instead of skipping.

## Gates are proven, not asserted

Every gate ships with a probe that injects a violation and asserts the gate fails
with its marker (`gokit gates honesty`, ADR-0011). The probes run as part of the
full profile, so a gate that cannot fail fails the build.

## Drift

Generated artifacts are regenerated by the gate and compared against the tree:
`internal/db/gen` from sqlc, `contracts/generated.go` from the pinned snapshot. A
difference fails, which is why generated code and the queries it comes from land in
the same commit.

## The two lanes

The SQLite lane runs the full profile; the pg lane runs its own profile in a second
job with a `postgres:17` service and `DATABASE_URL` set. Contract suites and
integration tests run on both, and the schema inventory test keeps the two migration
trees aligned.

## Scaffolded output

`make scaffold-smoke` copies the tree, scaffolds a feature and an endpoint,
regenerates artifacts, and runs the full profile in the copy. It exists because
generated code that breaks the gate is a bug in the generator, and the check has to
run somewhere real. It runs in CI.

## Secrets

`gokit` scans `git ls-files` for secret-shaped text as a step of the fast profile:
private keys, cloud access keys, provider keys, service-account JSON. Findings report
file, line, and pattern — never the match — and two entries are allowlisted with
their reasons. `make tools` pins the toolchain, and `gokit doctor` compares what is
installed with what the Makefile pins.
