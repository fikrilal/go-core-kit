# 1.6 — Redis Platform

- Status: completed
- Owner: Core kit maintainers
- Risk: low
- Date: 2026-10-10
- Roadmap: `docs/exec-plans/roadmap.md` task 1.6
- Related ADRs: ADR-0006 (Redis roles: queue, idempotency, rate limits), ADR-0008 (boundaries)

## Objective

Add `internal/platform/redis`: the platform's Redis handle (open from `REDIS_URL`, ping, close), the key-naming convention, and the pieces readiness wiring needs — plus in-process test coverage via `miniredis`.

## Constraints

- New dependencies: `github.com/redis/go-redis/v9` (runtime) and `github.com/alicebob/miniredis/v2` (tests only; no Docker needed).
- The driver stays confined: depguard denies `github.com/redis/go-redis` inside `internal/features/**` (added in this task).
- No connection checks at startup — availability belongs to the readiness probe (`/ready`), not boot.
- The package must not import `health` or `httpx`: idempotency middleware (1.8) will import this package from `httpx`, and `health` already imports `httpx` — importing upward would create a cycle.

## Impact Areas

- API / contract: no
- DB / migrations: no
- Auth / session: no
- Queue / jobs: no (asynq wiring comes later and builds its own connection options from the URL)
- Config / secrets: no (`REDIS_URL` already exists)
- Observability: no
- CI / release: no

## Acceptance Criteria

1. `Open(url)` parses the URL and returns a platform client; invalid URLs fail with a wrapped error; `MustOpen` panics on invalid configuration.
2. `Client.Ping(ctx)` returns a wrapped error for readiness checks; `health.Check{Name: "redis", Verify: client.Ping}` slots in at the composition root (1.10).
3. `Key(parts...)` joins segments with `:` (the namespacing convention).
4. Tests run without Docker: invalid URL, key joining, and ping success/failure against `miniredis` (including failure after the server closes).
5. depguard denies the Redis driver inside features; `make verify` green.

## Decision Log

- 2026-10-10: The platform handle hides the driver behind an unexported field with explicit methods (`Ping`, `Close`); an escape hatch for data operations arrives with the idempotency task that needs it, not before.
- 2026-10-10: `Check()` was deliberately not placed here — `health` imports `httpx`, and `httpx` will import this package for idempotency; upward imports would cycle. The composition root composes the check instead.
- 2026-10-10: `miniredis` is the test strategy for Redis-backed code — in-process, no Docker, and it can simulate failures.
