# 1.11 — gokit v0 Harness

- Status: completed
- Owner: Core kit maintainers
- Risk: low
- Date: 2026-10-10
- Roadmap: `docs/exec-plans/roadmap.md` task 1.11
- Related ADRs: ADR-0010 (gokit CLI and the single verify gate)

## Objective

Turn `tools/gokit` into the typed harness: a pure command parser, verification profiles (`fast`/`full`/`ci`) with fail-fast steps and advisory budgets, a `doctor`, and `make verify` delegating to the full profile (CI follows through it).

## Constraints

- Profiles are the single definition of the gate; the Makefile keeps only granular convenience targets and delegates `verify`.
- Steps run from the repository root; `doctor` verifies the working directory looks like this repository.
- Drift joins the full profile (1.9b follow-up): full/ci require `sqlc` from `make tools`.
- `knowledge` runs first in the fast profile — 1.12's checks plug straight in.
- Exit codes: 0 success, 1 failure, 2 usage.

## Impact Areas

- API / contract: no
- DB / migrations: no (drift wiring only)
- Auth / session: no
- Queue / jobs: no
- Config / secrets: no
- Observability: no
- CI / release: yes (`make verify` now delegates; CI drops its redundant drift step)

## Acceptance Criteria

1. `gokit verify --profile fast|full|ci` (default `full`) runs fail-fast steps — fast: knowledge, fmt-check, vet, lint, test; full: fast + build, build-pg, drift; ci: full (runtime lane joins in phase 7). Unknown profile or argument → usage error, exit 2.
2. `gokit doctor` inspects repository files, Go vs the `go.mod` directive, golangci-lint and sqlc versions against the Makefile pins, and the git work tree; exits 1 when errors exist.
3. The command parser is pure and unit-tested; the runner is fail-fast-tested; profile composition (ci ⊇ full ⊇ fast) is asserted.
4. `make verify` delegates to `--profile full`; CI drops its now-redundant drift step.
5. `make verify` green on the new wiring.

## Decision Log

- 2026-10-10: Step commands live in the profile registry (not shelling to make targets) so the gate is defined once; Makefile granular targets stay as convenience aliases for humans.
- 2026-10-10: Tool versions stay pinned in the Makefile; `doctor` parses the pins from it (repo-local CLIs parse repo files — the project-map precedent) rather than duplicating versions.
- 2026-10-10: Duration budgets are advisory (warn only), 2-minute default per step.
- 2026-10-10: gokit cancels running steps on SIGINT/SIGTERM via `signal.NotifyContext`.
