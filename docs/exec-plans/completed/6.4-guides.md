# 6.4 — Guides

## Objective

Four guides under `docs/guide/`, written from what the kit actually does, so a
newcomer can add a feature, add an endpoint, add a knob, or add a job without
reverse-engineering the code.

## What landed

- `docs/guide/adding-a-feature.md` — the scaffold command, the marker-based
  wiring, where SQL/time/responses belong, the boundary rules the linter
  enforces, the cross-feature dependency rule with `auth` -> `me` as the worked
  example, and the removal command.
- `docs/guide/adding-an-endpoint.md` — the contract-owned-by-backend rule, the
  snapshot/allowlist hand-off, what the scaffolder writes, the `TODO`s to fill,
  guard and idempotency conventions, and the scaffold smoke as the proof that the
  templates stay gate-clean.
- `docs/guide/config.md` — the env-tag struct, env.example as the deployment
  contract, validation at load, the three gates that police it, secret handling
  (including the FCM credential forms), and the fail-closed rule for
  unconfigured collaborators.
- `docs/guide/jobs.md` — the queue lanes and why an unpolled queue never runs,
  the `queue.Meta` envelope, provider-gated handler registration, skips as
  successes versus retryable failures, `queue.Scheduler`'s deterministic delayed
  ids and re-arm behavior, and how the lane is tested without a live Redis.

`docs/README.md` links all four under a Guides section.

## Acceptance checks

1. `gokit knowledge check` passes: every markdown link resolves, and the index
   lists the new files.
2. No guide claims behavior the code does not have — each statement is traceable
   to a command, a rule, or a test in this repository.

## Outcome — landed 2026-10-15

All four guides are written and indexed; `gokit knowledge check` reports ok for
env.example parity, the project map, markdown links, and the ADR index, and
`make verify` full profile passed.

## Notes

- The guides state the rules the gate enforces rather than duplicating the lint
  config; when a rule changes, the standards and the lint config are the source of
  truth and the guide follows.
