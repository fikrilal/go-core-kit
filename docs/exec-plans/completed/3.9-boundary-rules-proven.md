# 3.9 — Boundary rules proven with the first feature

- Status: completed
- Owner: Core kit maintainers
- Risk: medium
- Date: 2026-10-11
- Roadmap: `docs/exec-plans/roadmap.md` task 3.9
- Related ADRs: ADR-0008 (boundaries via golangci-lint), ADR-0010 (verify gate)

## Objective

Prove the feature-era boundaries are live: `time.Now()` is rejected in feature code (injected clock), raw JSON is rejected in features (`httpx` helpers), and platform must not import features. Extend `gokit gates honesty` with one scenario per rule so `make verify` exercises them every run.

## Ground truth (from the investigation)

- `.golangci.yml` already carries the `forbidigo` `^time\.Now$` rule and the `depguard` rules (`features-no-raw-json`, `platform-no-features`), landed with the harness; they were inert until features existed. No config change is needed — they need to be *verified*.
- Empirical probes confirmed: raw JSON (`encoding/json` import in `internal/features/**`) and platform→features imports are rejected by depguard with their exact messages; `time.Now` is rejected by forbidigo with its message.
- Edge found while probing: golangci-lint filters other linters' findings inside **unused, single-line** declarations (an unused single-line `func now() time.Time { return time.Now() }` produced no forbidigo finding, while the same body multi-line, or exported/used, or with `unused` disabled, fired). Real service code is used code, so enforcement holds; fixtures therefore use realistic exported multi-line shapes.

## Constraints

- One fixture per rule, in its own package directory, so each scenario asserts exactly one marker:
  - driver confinement (existing) — `internal/features/violation/drivers/`
  - raw JSON — `internal/features/violation/rawjson/`
  - `time.Now` — `internal/features/violation/clock/`
  - platform→features — `internal/platform/violation/`
- Fixtures are created and removed per scenario; `internal/features` is removed only when the run created it; `internal/platform` always exists.
- No `.golangci.yml` changes: the rules are already correct; the task is proof, not new policy.
