## Objective

Close the seven findings from the automated review of 1.9a. Every finding was independently verified before fixing; two are real bugs (one critical), and the fixes land with regression tests that reproduce the original failure.

## Findings to fixes

1. **[Critical] `InTx` panic leaves the pooled connection checked out.** Fixed with `defer func() { _ = tx.Rollback() }()` right after `BeginTx` — rollback runs during stack unwinding and is a no-op after a successful commit. Regression test: panics inside `InTx`, recovers, asserts a follow-up query succeeds within 5 s (previously: `context deadline exceeded`).
2. **[High] `RFC3339Nano` emits variable-width fractions, inverting SQLite TEXT ordering.** Fixed with the fixed-width layout `2006-01-02T15:04:05.000000000Z07:00`. Pinned by a unit test (fixed width + lexicographic order == chronological order) and an integration test (`ORDER BY created_at ASC` over 0 ns / 1 ns / 100 ms / 150 ms rows).
3. **[Low] `parse()` tolerance for SQLite-native `YYYY-MM-DD HH:MM:SS[.fff]`.** Added the no-offset layout. Defensive only: the portable subset bans `datetime()`/`CURRENT_TIMESTAMP`, so these values should not exist under our own rules.
4. **[Medium] goose package globals + implicit `fsys/"sqlite"` contract.** `Migrate` now uses the instance-scoped `goose.NewProvider` with `fs.Sub(fsys, "sqlite")` and `goose.WithLogger(goose.NopLogger())`; no global setters.
5. **[Low] Pragma test covered 2 of 4 pragmas.** Added `busy_timeout=5000` and `synchronous=1` assertions.
6. **[Nit] Local agent mods could be committed accidentally.** `.gitignore` gains `.commandcode/mods/` — skills under `.commandcode/skills/` stay tracked (family pattern, verified against mobile-core-kit).
7. **[Nit] Completed exec plans still say `Status: active`.** All nine completed plans get `Status: completed`; the fix plan itself follows suit.
